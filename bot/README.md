# مساعد واتساب لصالون ياسمين

يرد على الزبائن على رقم الصالون (واتساب أعمال) ويسجّل **طلبات حجز «بانتظار التأكيد»** تظهر بالتطبيق، وصاحبة الصالون تؤكد أو ترفض بضغطة، وتصل الزبونة رسالة بالنتيجة.

## كيف يشتغل

```
رسالة الزبونة ──► [ناقل واتساب] ──► agent.js ──► Gemini (يفهم الطلب ويستدعي أدوات محدودة)
                                         │
                                         ├─ check_availability  أوقات فاضية
                                         ├─ create_booking      طلب حجز (pending)
                                         ├─ my_bookings / cancel_booking   حجوزات الزبونة نفسها فقط
                                         └─ handoff_to_human    ملاحظة مثبّتة بالتطبيق + البوت يسكت 12 ساعة
التأكيد/الرفض من التطبيق ──► notify.js (يراقب Firestore) ──► رسالة للزبونة
```

- `lib/booking.js` منطق الحجز (الأوقات، التعارض بمعاملة Firestore، حد 3 حجوزات مفتوحة للرقم الواحد).
- `lib/agent.js` الوكيل: التعليمات، الأدوات، وحواجز الأمان. `lib/gemini.js` عميل Gemini. `lib/notify.js` رسائل التأكيد.
- **ناقل واتساب** (الربط بالرقم نفسه) لسا ما انكتب: ينتظر قرار الطريقة (انظر آخر الملف).

## الحماية (كلها مختبرة بـ `npm run test:bot`)

- رقم الزبونة **دائماً من المحادثة** وليس من الموديل: ما بيقدر يحجز/يلغي/يشوف باسم رقم ثاني (اكتُشفت وصُلّحت ثغرة بهالنقطة بالاختبارات).
- الموديل ما بيلمس قاعدة البيانات؛ فقط الدوال أعلاه، وكل مدخل يُتحقق منه بالكود (تاريخ، وقت من الشبكة، أيام العطلة، دوام، تعارض).
- تجاهل المجموعات والستاتس، منع المعالجة المزدوجة لنفس الرسالة، حد 25 رسالة/ساعة لكل زبونة، حد 800 استدعاء Gemini يومياً.
- لو كتبت صاحبة الصالون بنفسها بالمحادثة، البوت يسكت 6 ساعات.
- لو تعطّل Gemini: رد لطيف بدون أي تفاصيل تقنية + ملاحظة بالتطبيق.

## الإعداد

1. عدّل `salon.config.js`: الخدمات والأسعار (`price: null` = يحدده الصالون)، أيام العطلة، المنطقة الزمنية (`SALON_TZ`).
2. متغيرات البيئة (لا تضعها بالكود ولا بـ git):
   - `GEMINI_API_KEY` من https://aistudio.google.com/apikey
   - `FIREBASE_SERVICE_ACCOUNT` نص JSON لمفتاح حساب الخدمة (أو `GOOGLE_APPLICATION_CREDENTIALS` مسار الملف). هذا المفتاح يتجاوز قواعد الأمان: أبقِه على جهاز البوت فقط.
3. الاختبار: `npm run test:bot` من جذر المشروع (يحتاج Java للمحاكي).

## ملاحظات مهمة

- **الخصوصية:** طبقة Gemini المجانية تسمح لـ Google باستخدام المحتوى لتحسين منتجاتها. رسائل الزبائن (أسماء وأرقام) ستمر بها. للخصوصية الكاملة استخدم الطبقة المدفوعة.
- **المكتبات غير الرسمية تخالف شروط واتساب** وقد يُحظر الرقم. خفّفنا الخطر بأن البوت يرد فقط على من كتب أولاً، وبحدود المعدّل، لكنه لا يُلغى.
- **أمان الرد:** الحجز دائماً «بانتظار التأكيد»، فأي خطأ من الذكاء الاصطناعي تلتقطه صاحبة الصالون قبل ما يصير موعد حقيقي.
