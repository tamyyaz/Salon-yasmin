# صالون ياسمين — نظام حجز المواعيد

صفحة ويب خاصة بالصالون (مقفولة بكلمة سر) تُثبَّت على التابلت من Chrome وتفتح كتطبيق:
حجز مواعيد، حضور/غياب، دفعات والمتبقي على كل زبون، زبائن مفاجئون، وملاحظات.

- **الواجهة:** HTML/CSS/JS عربي RTL بهوية وردية/فضية، زهور مرسومة SVG ومطر زهور متحرك.
- **الاستضافة:** Firebase Hosting (`https://<project-id>.web.app`) — نشر تلقائي من GitHub.
- **البيانات:** Cloud Firestore، تتزامن لحظياً بين الأجهزة وتعمل **بدون إنترنت** (تُرسل التغييرات عند عودته).
- **الدخول:** Firebase Authentication — حساب واحد للصالون + قواعد أمان تمنع أي شخص آخر من قراءة أو كتابة أي شيء.
- لا يوجد سيرفر ولا تكلفة شهرية ضمن الخطة المجانية (Spark).

> **لماذا ليس Vercel؟** Vercel يشغّل الكود كدوال مؤقتة (لا يحفظ ملفات) ودومين `web.app` تابع لـ Firebase ولا يمكن توجيهه إليه.
> Firebase يعطي الاستضافة والقاعدة والدخول والدومين في مكان واحد. (نسخة Node + SQLite القديمة موجودة في سجل git عند الـ commit `64efbbf`.)

**للنشر خطوة بخطوة: [DEPLOY.md](DEPLOY.md)**

## المزايا

- **اليوم**: مواعيد اليوم + إحصائيات (حجوزات، حضروا، لم يحضروا، مفاجئون، المحصّل اليوم، إجمالي المتبقي على الزبائن).
- **حجز موعد**: الاسم، الرقم، التاريخ، الساعة (ساعات سريعة بلمسة)، الخدمة، السعر، عربون، ملاحظة. تنبيه عند تعارض الوقت وتعبئة الاسم من الرقم.
- **حضر / لم يحضر / إلغاء** بضغطة، **دفعات** متعددة لكل موعد والمتبقي تلقائي.
- **زبون مفاجئ**: تسجيل سريع كحاضر الآن مع الدفع.
- **الزبائن**: سجل كل زبون وما عليه، مع اتصال وواتساب. **الملاحظات**: تثبيت وإنجاز.
- **وضع التابلت**: أزرار كبيرة للمس، تخطيط أفقي/عمودي، تحديث لحظي، يبقي الشاشة مفتوحة (زر ☀)، شريط انقطاع الاتصال، وتثبيت كتطبيق (PWA).
- **الخدمات والأسعار ومعلومات الصالون والأسئلة الشائعة** تُدار من التطبيق، وهي مصدر معلومات مساعد واتساب.
- **مساعد واتساب** (مجلد `bot/`): بوت مخصص على رقم الصالون يجاوب الزبائن بذكاء (Gemini) ويسجّل طلبات حجز «بانتظار التأكيد»؛ أيقونة واتساب بالتطبيق تعرض حالته وQR الربط. انظر `bot/README.md`.
- **نسخة احتياطية** JSON بضغطة من صفحة الملاحظات.

## التطوير محلياً

```bash
npm install
npm run dev        # يبني الموقع + يشغّل محاكي Firebase + يخدم http://localhost:5000
```

يحتاج Node 22+ و Java (للمحاكي). على `localhost` الموقع يتصل **بالمحاكي فقط** وليس بمشروعك الحقيقي؛
أول كلمة سر تكتبها تنشئ الحساب في المحاكي.

| الأمر | الوظيفة |
|---|---|
| `npm run build` | يبني `dist/` (الملفات الثابتة + حزمة التطبيق) |
| `npm test` | اختبارات المنطق (سريعة، بدون Firebase) |
| `npm run test:emu` | اختبارات قواعد الأمان وطبقة البيانات على محاكي Firebase |
| `npm run deploy` | نشر يدوي (Hosting + قواعد Firestore) بعد `firebase login` |

## هيكل المشروع

```
public/            ملفات ثابتة: index.html، style.css، fx.js (مطر الزهور)، sw.js، manifest، الأيقونات، art/ (رسومات SVG)
src/config.js      إعداداتك: اسم الصالون، العملة، ساعات الدوام، إعدادات Firebase
src/app.js         الواجهة وكل الشاشات
src/store.js       طبقة Firebase: الدخول، المزامنة، الدفعات، الزبائن، الإحصائيات
src/logic.js       منطق صافٍ: تحقق، أرصدة، تجميع الزبائن (مختبَر بدون Firebase)
firestore.rules    قواعد الأمان (حساب الصالون فقط + تحقق من شكل البيانات)
firebase.json      Hosting + رؤوس الأمان (CSP) + المحاكي
.github/workflows  نشر تلقائي عند الدمج في main + اختبارات المحاكي
```

## ملاحظات عن البيانات

- يُبقي التطبيق حيّاً آخر **120 يوماً** من المواعيد + كل موعد عليه متبقٍ مهما كان قديماً؛ أما الأقدم فيُجلب عند الطلب
  (فتح يوم قديم، أو سجل زبون). هكذا تبقى قراءات Firestore قليلة حتى بعد سنوات ضمن الحصة المجانية (50 ألف قراءة يومياً).
- قائمة «الزبائن» و«المواعيد السابقة» تعرض هذه الفترة؛ سجل أي زبون كامل يظهر عند فتحه.
- مفتاح Firebase في `config.js` **ليس سراً** (يعرّف المشروع فقط). الحماية الحقيقية: كلمة السر + `firestore.rules`.
- عند «خروج» تُمسح نسخة البيانات المخزنة على التابلت.

## الرسومات والحركة

- الزهور والقلوب والفراشات رسومات SVG ثنائية الأبعاد في `public/art/` (مرسومة للمشروع).
- `public/fx.js` يرسم «مطر الزهور» البطيء: تمايل وتقلّب، قلوب تنبض، نجوم تلمع، فراشات ترفرف، وتبتعد الزهور بلطف عن الإصبع.
  يقلّل نفسه تلقائياً إذا كان الجهاز بطيئاً، ويحترم إعداد «تقليل الحركة»، ويمكن إيقافه بزر الزهرة.
