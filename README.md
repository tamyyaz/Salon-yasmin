# صالون ياسمين — نظام حجز المواعيد

موقع خاص بالصالون فقط (مقفول بكلمة سر): حجز مواعيد، حضور/غياب، دفعات والمتبقي على كل زبون، زبائن مفاجئون، وملاحظات.
Node.js + Express + SQLite، واجهة عربية RTL بهوية وردية/فضية.

## التشغيل

```bash
npm install
cp .env.example .env      # ثم غيّر SALON_PASSWORD
npm start                 # http://localhost:3000
```

المتطلبات: Node.js 22 أو أحدث.

| متغير (.env) | الوصف |
|---|---|
| `SALON_PASSWORD` | كلمة السر (6 أحرف على الأقل) — **إجباري** |
| `SALON_NAME` | اسم الصالون الظاهر في الموقع |
| `CURRENCY` | رمز العملة (مثلاً `₪` أو `د.أ`) |
| `PORT` | المنفذ (الافتراضي 3000) |
| `DATA_DIR` | مكان حفظ قاعدة البيانات (الافتراضي `./data`) |
| `OPEN_HOUR` / `CLOSE_HOUR` / `SLOT_MINUTES` | ساعات الدوام وطول الخانة في اختيار الوقت السريع (9 / 21 / 30) |
| `TRUST_PROXY` | `1` إذا كان الموقع خلف Nginx/Caddy/Cloudflare |

## المزايا

- **اليوم**: مواعيد اليوم مع إحصائيات (حجوزات، حضروا، لم يحضروا، مفاجئون، المحصّل اليوم، إجمالي المتبقي على الزبائن).
- **حجز موعد**: الاسم، الرقم، التاريخ، الساعة، الخدمة، السعر، عربون، ملاحظة. تنبيه إذا كان الوقت محجوزاً، وتعبئة الاسم تلقائياً من الرقم.
- **حضر / لم يحضر / إلغاء** بضغطة واحدة.
- **دفعات**: عدة دفعات لكل موعد والمتبقي يُحسب تلقائياً.
- **زبون مفاجئ**: تسجيل سريع كحاضر الآن، مع الدفع.
- **الزبائن**: سجل كل زبون وإجمالي المتبقي عليه، مع روابط اتصال وواتساب.
- **الملاحظات**: ملاحظات عامة للصالون مع تثبيت وإنجاز.

## الأمان

- كل الـ API مقفول بجلسة موقّعة (HMAC) في كوكي `HttpOnly` + `SameSite=Strict` (+ `Secure` خلف HTTPS) صالحة 90 يوماً وتتجدد تلقائياً أثناء الاستخدام.
- قفل مؤقت (15 دقيقة) بعد 5 محاولات فاشلة لنفس الـ IP.
- **انشر الموقع خلف HTTPS دائماً.** إذا كان خلف proxy (Nginx/Cloudflare) ضع `TRUST_PROXY=1` في `.env` ليُحسب الـ IP الصحيح لقفل المحاولات.
- النسخ الاحتياطي: انسخ ملف `data/salon.db` بشكل دوري.

## وضع التابلت (دائم الفتح)

- الواجهة مصممة للمس أولاً: أزرار كبيرة، تخطيط أفقي (قائمة المواعيد + إحصائيات جانبية) وعمودي، وشريط أزرار سفلي للحجز السريع.
- **ساعات سريعة** بلمسة واحدة عند الحجز (الساعات المحجوزة تظهر باهتة)، ونوافذ تأكيد بتصميم الموقع.
- **تحديث تلقائي هادئ** كل 30 ثانية (لا يقاطع من يكتب)، وينتقل لليوم الجديد عند منتصف الليل.
- **PWA**: يُثبَّت على الشاشة الرئيسية ويفتح بملء الشاشة. زر ☀ يُبقي الشاشة مفتوحة (Wake Lock)، وزر الزهرة يوقف مطر الزهور.
- شريط تنبيه عند انقطاع الإنترنت، ونسخ احتياطي تلقائي (كل 6 ساعات، آخر 14 يوم) مع تحميل يدوي من صفحة الملاحظات.
- `GET /healthz` لمراقبة التشغيل.

## الرسومات والحركة

- كل الزهور والقلوب والفراشات رسومات SVG ثنائية الأبعاد في `public/art/` (مرسومة خصيصاً للمشروع، بدون صور واقعية).
- `public/fx.js` يرسم «مطر الزهور» البطيء بالخلفية على canvas: تمايل، تقلّب، قلوب تنبض، نجوم فضية تلمع، فراشات ترفرف، والزهور تبتعد بلطف عن المؤشر/الإصبع.
- يحترم إعداد النظام «تقليل الحركة» (يعرض لقطة ثابتة بدون حركة) ويتوقف تلقائياً عندما تكون التبويبة مخفية.
